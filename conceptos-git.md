# Conceptos básicos de Git

- **Repositorio**: Carpeta controlada por Git - la versión final guardadas.
- **Commit**: Guardar al cambio o asentar al cambio que se está haciendo, el registro que hacés en el proyecto; un cambio o modificación con comentario.
- **Staging Area**: "area en construcción, donde están los cambios a punto de guardarse en versionado".
- **Branch**: rama, línea de tiempo alternativa.
- **Merge**: Mezclar las ramas, unen las líneas de tiempo.
- **Working Directory**: Directorio de trabajo en git donde editamos los archivos
